# seqRdna 0.99.5

## New features

- Initial release of seqRdna.
- Added functions to estimate relative and absolute
  ribosomal DNA (rDNA) copy number.
- Added functions for calculating regional DNA
  methylation metrics.
- Added differential methylation analysis at
  individual CpG sites and across rDNA regions.
- Added support for mouse, rat and human rDNA
  reference annotations.

## Documentation

- Added an introductory vignette demonstrating
  the main analysis workflow.
- Added example datasets and runnable examples.
